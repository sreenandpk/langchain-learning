# LangChain

LangChain is a framework for building applications powered by large language models.

It provides components for working with models, prompts, documents, embeddings, vector stores, retrievers, tools, and agents.

LangChain can be used to build RAG applications where relevant information is retrieved from external data before being provided to an LLM.

LangChain supports multiple model providers, including Google Gemini, OpenAI, and Anthropic.
